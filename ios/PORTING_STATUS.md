# iOS port status

## Implemented in source

- `VT3_IOS` CMake build branch for iOS ARM64
- Objective-C/SDL3 entry point which launches the translated game from bundled `image.bin`
- Bundled `shaders.pack`, generated by the existing build script
- MoltenVK framework integration through CMake
- Documents/data2 game-data path exposed to the Files app
- SDL finger-event forwarding into the existing touch-controller input system
- GitHub Actions workflow to build dependencies, translate an owner-provided executable, and
  package an unsigned IPA artifact

## Not yet verified

No Xcode/iOS SDK is available in the current environment, so the iOS target has not been compiled or
launched on-device here. The workflow is a first complete build attempt, not a tested release. The
first GitHub Actions run may require fixes for upstream SDL3/MoltenVK target names, Xcode bundle
layout, and framework linking. A real iPhone test is required before calling the port playable.
